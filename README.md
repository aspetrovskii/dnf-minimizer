# DNF Minimizer

Десктопное приложение на **Qt 6** для пошаговой минимизации **ДНФ** (дизъюнктивной нормальной формы) булевой функции, заданной на всех `2^N` наборах переменных (значения `0` или `1`).

Алгоритм строит таблицу по принципу минимизирующих карт, затем перебирает покрытия и выбирает ДНФ с минимальным числом литералов. Интерфейс показывает каждый этап заливки таблицы и итоговую формулу.

## Возможности

- Задание числа переменных `N` и вектора значений функции длиной `2^N`
- Пошаговое выполнение алгоритма (`step1` → `step2` → `step3` → `computeAnswer`)
- Визуализация таблицы минимизатора с закреплёнными заголовками и синхронным скроллом
- Панель бинарных наборов переменных и столбец значений функции
- Отображение минимальной ДНФ с копированием в буфер обмена
- Обработка константных функций (`0` и `1`)

## Требования

- **C++17**
- **Qt 6** (рекомендуется 6.5+), модули Core, Gui, Widgets
- **qmake** для Qt 6 (`qmake6` на системах с несколькими версиями Qt)
- Компилятор с поддержкой C++17 (GCC, Clang, MSVC)

## Сборка

Из корня репозитория:

```bash
mkdir build && cd build
qmake6 ../dnf_minimizer.pro
make -j
```

Исполняемый файл: `build/dnf_minimizer`.

Альтернатива — открыть `dnf_minimizer.pro` в Qt Creator и собрать проект оттуда.

## Запуск

```bash
./build/dnf_minimizer
```

1. Укажите `N` (число переменных).
2. Задайте значения функции в левом столбце (клик по ячейке переключает `0`/`1`).
3. Нажимайте **Step** для поочерёдного прохождения стадий алгоритма.
4. После завершения минимизация отображается в нижней панели; клик по ответу копирует формулу в буфер.

Кнопки **Reset** / **Restart** сбрасывают прогресс минимизации или пересоздают сессию. **Zoom** масштабирует центральную таблицу.

## Бэкенд (кратко)

- `Minimizer(vector<ll> func, ll n)` — `func` длины `2^n`, элементы `0` или `1`.
- `makeStep()` — один шаг; `stage()` возвращает текущую стадию (`0` … `4`).
- `table()` — `map` столбцов (маски `1 … 2^n-1`), в ячейках коды заливки `0…4`.
- `answer()` — результат как `MinDNF` (набор дизъюнктов с минимальным весом).

Порядок столбцов задаётся `PopcountComparator`: сначала по числу единиц в маске, затем по значению маски.
